### 📦 [InvenSight — Retail Analytics & Demand Forecasting](https://github.com/Suthishkumark/invensight)

A retail analytics project focused on transforming store-level data into useful inventory and business insights.

- Worked with retail data covering **45 stores and 81 departments**.

- Used **DuckDB** as the analytical data store.
- Built dimensional data models with **dbt**.
- Developed a **Streamlit** dashboard to monitor retail KPIs and stockout risks.

### 📡 [Telecom Network Anomaly Detection System](https://github.com/Suthishkumark/Network-Anomaly-Detection-System)

A machine-learning project to identify unusual patterns in telecom network performance data.

- Processed and prepared **36K+ telecom records** using Python and Pandas.
- Built an anomaly detection model using **XGBoost**.
- Compared machine-learning models during experimentation.
- Evaluated model performance using precision, recall and F1-score.
- Developed a **Flask REST API** with CSV upload functionality.

**Tech stack:** Python · Pandas · NumPy · Scikit-learn · XGBoost · Flask
